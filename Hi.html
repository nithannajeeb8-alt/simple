UPI Screenshot Reader

Reads GPay, PhonePe, Paytm, BHIM and bank-app payment screenshots, then checks the fields against UPI rules.

How it works

A vision model reads each screenshot and returns labelled fields, so it understands that PhonePe’s “UPI Ref No”, GPay’s “UPI transaction ID” and Paytm’s “UTR” are the same 12-digit reference. Then the page validates the result in code: amount parsed from Indian grouping (₹1,50,000), reference must be exactly 12 digits, UPI ID must look like name@bank. Anything that fails is flagged so you can fix it by eye. Images stay in your browser session and are sent only to Claude for reading.
