# Quiet Pages

A private, mobile-first diary Progressive Web App with an optional local AI companion. See [README-QUIET-PAGES-V23.md](README-QUIET-PAGES-V23.md) for the final release notes, privacy details, references, limits, and deployment steps.

**Before updating:** export a JSON backup in Settings. The project keeps diary data in browser storage, but browsers can clear it.

The project is plain HTML, CSS, and JavaScript. No npm build step is required. All app iconography is local SVG and typography uses system fonts. The optional AI runtime/model is fetched only when the user asks to discover/load a model.
